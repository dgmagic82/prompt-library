# Разбор личного промпта по CLEAR

Исходник (v0): мой рабочий файл для эксперимента с расстановкой мебели Hoff. Кадр из Blender отдаётся в ChatGPT (GPT Image), модель должна сделать из него фото, не сдвинув мебель. Файл состоял из инструкции «как запускать», общего блока, двух блоков мебели под конкретные кадры и блока «если что-то уехало».

## Что было в каждой части

| Часть | Где лежало в v0 | Проблема для команды |
|---|---|---|
| **Task** | Первая строка общего блока: «Turn the attached 3D render into a photorealistic photograph». | Задача размазана: «меняй только материалы и свет» стоит отдельным абзацем ниже, после правил геометрии. |
| **Context** | «Exact 3D model of a real room» в промпте. Главное было вне промпта: «Я прогоню проверку контуров», допуск 3 px, ID-карта объектов. | Скрытый контекст. Модель не знает, что её будут мерить по пикселям, коллега не знает, что есть проверка. |
| **Input** | Кадр прикрепляется вручную. Правило «больше ничего не прикладывай» жило в инструкции для человека. Отделка комнаты (дуб, белые стены, двор за окном) и мебель зашиты текстом под одну квартиру. | Промпт работает только для двух комнат одной квартиры. Новая комната означает переписать текст руками. |
| **Output** | Пропорция 3:2 внутри правил камеры, размер 1536 × 1024 в инструкции, «No people, no text» в конце абзаца про свет. | Требования к результату разбросаны по трём местам, часть из них не в промпте. |

## Дублирование

- «Keep every shape exactly as in the render» повторялось в каждом блоке мебели, хотя то же правило уже стояло в общем блоке.
- Блок «если что-то уехало» заново пересказывал правило геометрии.
- Два почти одинаковых блока мебели отличались только списком предметов.

## Что сделано в v1.0

1. Четыре явных раздела TASK, CONTEXT, INPUT, OUTPUT, в каждом только своё.
2. Всё, что зависит от квартиры, вынесено в 7 переменных: `room_type`, `room_finishes`, `window_view`, `lighting`, `furniture_list`, `aspect_ratio`, `strict_note`.
3. Скрытый контекст поднят в промпт: «The photo will be checked against it edge by edge».
4. Правило «только один референс» перенесено из инструкции человеку в INPUT.
5. Правило геометрии записано один раз, в OUTPUT. Блок «если уехало» стал необязательной переменной `strict_note`.
6. Инструкция «как запускать» и критерии приёмки ушли в карточку промпта: это знание для человека, модели оно не нужно.

Итог по объёму. Промпт для спальни: v0 1749 символов, v1.0 с подставленными значениями 1653. Для гостиной 1724 и 1632. Экономия скромная, около 5 %, потому что почти весь текст это описание материалов, и оно осталось. Главный выигрыш в другом: неизменная часть шаблона занимает 1067 символов и подходит для любой комнаты, новая квартира заполняет переменные и не трогает текст.
