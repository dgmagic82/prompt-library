# Библиотека промптов

Командные промпты: у каждого есть шаблон с переменными, карточка с владельцем и версией, тест-кейсы.

## Каталог

| ID | Задача | Версия | Владелец | Теги |
|---|---|---|---|---|
| [render-to-photo](prompts/render-to-photo/card.md) | Фото комнаты из 3D-рендера без сдвига мебели | v1.0 | @dgmagic82 | `image` `interior` `3d-render` `geometry-lock` |

## Как устроен промпт

```
prompts/<id>/
  card.md       карточка: цель, переменные, пример входа и выхода, тест-кейсы, история версий
  template.md   шаблон, переменные в {{двойных скобках}}
  CLEAR.md      разбор исходного личного промпта и что изменено
  examples/     входные файлы и собранные промпты
```

## Правила

- У промпта один владелец. Он принимает изменения и отвечает за тест-кейсы.
- Версии по схеме vMAJOR.MINOR. MAJOR, если меняется набор переменных или смысл результата. MINOR, если правится формулировка.
- Изменение идёт через pull request: новая версия в карточке, строка в истории версий, прогон всех тест-кейсов.
